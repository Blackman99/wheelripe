Configuration

There is no config file. Everything is a flag, an Action input or an environment variable, and the defaults describe a typical 2026 deployment.

Target Python

-p / --python, env WHEELRIPE_PYTHON, default 3.15. Accepts 3.15, 3.15t, cp315, 315t. The t suffix means the free-threaded build, which has its own ABI: a cp315 or abi3 wheel does not load there, a cp315t or abi3t one does.

Platforms

--platform (repeat or comma-separate), or --all-platforms. Default linux-x86_64, macos-arm64, windows-amd64. Keys are listed in the reference.

Floors: glibc, musl, macOS

A wheel tagged manylinux_2_39_x86_64 needs glibc 2.39; on a 2.34 host pip skips it. Set the oldest system you deploy on and wheelripe judges with that floor, and tells you when the only wheels are for newer systems.

FlagDefaultApplies to
--glibc2.34linux-* (manylinux tags, including manylinux1/2010/2014)
--musl1.2musllinux-*
--macos14macos-* (arm64 also accepts universal2)

Failing

--fail-on sets the exit-1 threshold: bump (default: anything you have to change), blocked (only upstream blockers — useful for a "tell me when" job), build (also sdist-only packages), never (report only).

Pre-releases

--pre lets the suggested bump be a pre-release. Early in a CPython cycle, many projects ship wheels in an rc first.

Index

--index, env WHEELRIPE_INDEX, default https://pypi.org/pypi. Any server that implements the PyPI JSON API at <index>/<name>/json works. Simple-API-only indexes (PEP 691) are on the roadmap.

Environment variables

VariableEffect
WHEELRIPE_PYTHONDefault for --python.
WHEELRIPE_INDEXDefault for --index.
NO_COLORPlain text output.
HTTPS_PROXYStandard proxy support.

What gets read

FileNotes
uv.lockRegistry packages only; git, path and URL sources are skipped.
pylock.tomlPEP 751 lockfiles.
poetry.lock, Pipfile.lockAll locked packages.
requirements*.txtFollows -r, handles continuations and hashes; skips options, URLs and -e.
pyproject.toml[project] dependencies, optional dependencies and dependency groups.

Environment markers are evaluated per target, so pywin32; sys_platform == "win32" is only checked for Windows and shows as skipped elsewhere.
